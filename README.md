# HK Studio — Site web

Site vitrine bilingue (**FR / EN**) de **HK Studio**, startup studio d'innovation digitale basé à Abidjan, Côte d'Ivoire.

> Accélérer la transformation numérique des entreprises africaines grâce à l'IA, la data et l'intelligence économique.

## Structure

| Fichier | Page |
|---|---|
| `index.html` | Accueil |
| `services.html` | Services (6 expertises) |
| `roi.html` | Calculateur de ROI |
| `about.html` | À propos |
| `work.html` | Réalisations |
| `method.html` | Méthode |
| `contact.html` | Contact |
| `css/style.css` | Design system (thème clair / sombre) |
| `js/app.js` | Bilingue FR/EN, menu mobile, calculateur ROI |
| `assets/img/` | Logo et favicon |

## Lancer le site

Ouvrir `index.html` dans un navigateur. Aucune dépendance à installer (HTML / CSS / JS statique ; polices via Google Fonts).

## Fonctionnalités

- Bilingue **FR / EN** (sélecteur dans l'en-tête)
- Mode **clair / sombre**
- **Responsive** (mobile, tablette, desktop)
- **Calculateur de ROI** interactif (FCFA / EUR)
- Fiches d'études de cas dynamiques
